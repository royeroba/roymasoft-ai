The shape `/onboard-repo` writes. Every field carries evidence or the literal value `unknown`.

Target: **under ~150 lines.** This file loads in every session.

## Architecture

\`\`\`
src/
├── app/            routes (Next app router)
├── features/       feature modules — the unit of organization here
│   └── <name>/     components + hooks + types, colocated
├── lib/            shared utilities, no feature imports
├── server/         server actions and data access
└── types/          shared types
\`\`\`

Boundaries that hold: `lib/` never imports from `features/` (checked: `lib/format.ts`,
`lib/http.ts`). Data access only through `server/` (checked: `features/orders/actions.ts:12`,
`features/users/actions.ts:8`).

## Conventions

| Convention | Rule | Evidence |
|---|---|---|
| Components | PascalCase file and export | `features/orders/OrderList.tsx`, `features/users/UserCard.tsx` |
| Tests | colocated `*.spec.ts` next to the source | `lib/format.spec.ts`, `server/orders.spec.ts` |
| Errors | typed error classes, never bare throws | `server/errors.ts:5`, `server/orders.ts:44` |
| Docstrings | JSDoc on exported functions only | `lib/format.ts:10`, `server/orders.ts:22` |
| Imports | `@/` alias for src | `tsconfig.json` paths |

## Rules for filling it

**Evidence or `unknown`.** Every row cites a file, a manifest key, or a count. A field you could not
determine stays `unknown` and appears in the final checklist — never a plausible guess.

**Two occurrences minimum** before writing something down as a convention. One is a coincidence.

**Verbatim commands.** From `scripts`, the Makefile, CI or the README. Never normalized, never
invented.

**The testing block decides whether TDD is ever offered here.** When `available: false`, omit the
`tdd:` block entirely — there is nothing to configure.

**No secrets, no business logic, no client-identifying detail** beyond what a developer needs.

**Keep it short.** Anything a developer could find in ten seconds does not belong here. This file
pays its cost in every session; only facts that save a search earn their place.
